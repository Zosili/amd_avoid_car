# 雷达行为验证记录

对应指标：`metrics/metrics.csv` 的「雷达急停阈值」「雷达避障区间」。

## 1 阈值定义（PL 侧 `motor_decision.v`）

| 参数 | 值 | 含义 |
|---|---|---|
| `RADAR_ESTOP_MM` | 150 | 回波 <15 cm → 停车 + 中速 3 声 |
| `RADAR_ESTOP_REL_MM` | 250 | 回波 >25 cm 才解除急停（迟滞防抖） |
| `AVOID_DIST_MM` | 1000 | 15~100 cm 区间 → 差速原地转绕行（不停车、不响） |
| 扇区 | ±60° | PS 侧 `--corridor 60`（曾试 ±70°，杂波变多且配合误开的 `--flip-lr` 导致转向反向，已回退） |

## 2 板级观察记录

### 2.1 地面回波（2026-11-03 晚，雷达离地 1~2 cm）

```
帧OK 1625 坏 168  前方最近 0.15m @6°   右转
帧OK 2117 坏 176  前方最近 0.15m @6°   右转
帧OK 2599 坏 188  前方最近 0.15m @5°   右转
```

**现象**：回波距离恒定在 15 cm、角度固定在 5~10°，车辆持续朝一侧打转。

**判断**：雷达安装高度只有 1~2 cm，光束下缘打到地面/自身支架，形成恒定近距回波。
不是障碍物，也不是雷达故障。

**处理**：抬升安装（≥5 cm）后消失；若仍有残余，用 `ps_radar_fusion.py --avoid-min`
把有效下限抬到残余读数之上。

### 2.2 抬升后（同日）

```
帧OK 109552 坏 1073  前方最近 0.52m @314°  直行
帧OK 110032 坏 1089  前方最近 0.52m @316°  直行
```

**现象**：回波稳定在约 52 cm，状态恢复「直行」，不再误触发转向。

### 2.3 急停与掉线

| 验证项 | 操作 | 现象 | 结论 |
|---|---|---|---|
| 雷达急停 | 手挡到 15 cm 内 | 停车 + 中速 3 声（非连续长鸣） | 通过 |
| 急停解除 | 手移开至 25 cm 外 | 恢复按视觉状态行驶 | 通过 |
| 雷达掉线 | 拔 J4 上雷达杜邦线 | 约 0.5 s 后停车 + 中速 3 声，之后静音 | 通过 |
| 雷达恢复 | 重新插回 | 自动恢复，不需要重启服务 | 通过 |

> 掉线与急停都用**中速 3 声**而不是长鸣，是为了和「人贴到 1 m 内的连续长鸣」区分开——
> 否则现场分不清是雷达触发还是视觉触发（这是 2026-11-03 之前的一个误判根源）。

## 3 复现方法

```bash
# 板子 PS 网口，PC 设 192.168.2.1
ssh xilinx@192.168.2.99
tail -f /home/xilinx/radar/radar_run.log      # 实时看「前方最近 XXm @YY° 直行/左转/右转」
```

`bad`（坏帧）计数占比通常 <2%。若持续 >10%，检查杜邦线与共地。

> 说明：本记录为串口日志 + 人工观察，非仪器化测量。雷达自身的帧率/点数/有效点率
> 由 `host/radar/d6_stream.py --selftest` 输出，可重跑。
