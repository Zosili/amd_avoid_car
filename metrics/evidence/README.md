# metrics/evidence —— 波形 / 示波器 / 逻辑分析仪截图

对应 3.2.5.2「延迟与抖动类指标的波形、示波器或逻辑分析仪截图」。**空目录不代表没做，代表还没测**——测完把图放这里并在 `metrics.csv` 里引用。

## 命名规则

```
<指标>-<场景>-<YYYYMMDD>-<通道>.png
例：e2e_latency-person_left-20261105-ch1_pl_frame_ch2_pwm.png
```

## 必拍清单（按优先级）

| # | 拍什么 | 探点 | 能证明什么 |
|---|---|---|---|
| 1 | **端到端延迟**：相机帧到达 ↔ `pwm_l` 上升沿 | CH1 = PL 帧起始 GPIO；CH2 = `pwm_l` | 感知→执行的物理延迟（含调度、通信、驱动） |
| 2 | **PWM 载波与占空比** | `pwm_l` / `pwm_r`，20 kHz | PWM 频率与占空比正确（`speed=60` → 占空比 60 %） |
| 3 | **看门狗急停**：停写心跳后 300 ms 内 PWM 归零 | CH1 = AXI `HEARTBEAT`/`WR`，CH2 = `pwm_l` | PS 卡死也能停（安全逻辑的真实性） |
| 4 | **雷达 UART 帧**：`AA 55` 到 `CS` | 雷达 TXD | 230400 8N1、85 B 帧长、帧率 ~169 |
| 5 | **控制周期抖动**：两次决策的 `pwm` 更新间隔 | CH1 = 决策 GPIO 翻转 | 10 Hz ± 抖动（与 `latency_stats.py` 互证） |
| 6 | **供电跌落**：电机启停瞬间 12 V 轨 | 电池输出 | 解释「电机一转板子重启」类故障 |

## 记录要求

- 图上要能看出**时基**（µs/div、ms/div）与**触发条件**，不能只有一条波浪线。
- 每张图配一行说明写进 `metrics.csv` 的「证据文件」列，并在 `docs/architecture.md` 的对应指标处引用。
- 逻辑分析仪原始导出（`.csv`/`.sal`）放 `metrics/evidence/raw/`，截图放 `metrics/evidence/`。
