# 四档动作板级验证记录

对应指标：`metrics/metrics.csv` 的「四档动作正确性」。

- 验证对象：`fpga/build/top.bit`（md5 `cf922bec1ea1f8a09ebabf4e1b434d3d`，2026-11-03 21:10）
- 验证方式：轮子架空，PC 用 `metrics/scripts/test_cmd_frame.py` 每档发 5 字节距离帧
  （`AA 55` + dist(u16, mm) + steer），观察**轮子转向**与**蜂鸣器**。
- 发帧周期 20 Hz，每档观察 ≥5 s。

## 判据与结果

| 档位 | 发送帧（dist / steer） | 期望轮子 | 期望蜂鸣器 | 实测 | 结论 |
|---|---|---|---|---|---|
| 远距（CLEAR） | `5000 / 0` | 双轮正转 70% | 静音 | 双轮正转，无声 | 通过 |
| 预警（WARN） | `2000 / 0` | 双轮正转 | 每秒 120 ms 短鸣 | 双轮正转，间歇短鸣 | 通过 |
| 停车（STOP） | `500 / 0` | 停止 | 连续长鸣 | 立即停转，长鸣 | 通过 |
| 断流（SAFE） | 停止发帧 | 400 ms 后停止 | 静音 | 约 0.4 s 后停转，静音 | 通过 |

**4/4 通过。**

## 补充验证（2026-11-03 复核）

| 验证项 | 方法 | 结果 |
|---|---|---|
| `0xFFFE`（有人但测不出距离） | 发 `AA 55 FF FE 00` | 进入 WARN（短鸣、前进），**不再误判为「无人」** |
| 转向方向 | `steer=1` / `steer=2` 各观察 5 s | 左转/右转方向正确（曾因通道交叉反向，已修正） |
| 内轮反向（原地转） | `steer=1` 时观察内侧轮 | 内侧轮反转，车接近原地转向 |
| 换向抖动 | 每 100 ms 交替 `steer=1/2` | 该记录拍摄于 21:10 版（带 300 ms 保持）；22:27 版已移除保持，改为直连，转向更跟手但抖动时内轮换向更频繁 |
| 雷达急停 | 手挡雷达 15 cm 内 | 停车 + 中速 3 声 |
| 雷达掉线 | 拔雷达杜邦线 | 约 0.5 s 后停车 + 中速 3 声 |

## 复现方法

```bash
# 1) 板子进入 PL 网段，PC 设 192.168.1.102
# 2) 发四档
python metrics/scripts/test_cmd_frame.py --ip 192.168.1.10 --port 5000
```

脚本内部按上表逐档发帧并打印，可自行对照观察。

> 说明：本记录为**板级人工观察**（轮子转否、蜂鸣器响否），非仪器化测量。
> 需要波形级证据的项目见 `fpga/report/verification.md` 第 3 节。
